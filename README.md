# Dr. Zia Ul Islam — Aesthetic & Plastic Surgery Website

A responsive, multi-section static website with a cream/ivory editorial visual system inspired by the supplied Instagram screenshot.

## Project structure

- `index.html` — page content and semantic structure
- `css/style.css` — responsive styling, layouts, transitions and reduced-motion support
- `js/main.js` — mobile navigation, reveal-on-scroll and image sequences
- `assets/dr-zia-ul-islam.png` — supplied doctor portrait with transparency
- `assets/README.md` — notes on externally hosted stock photographs

## Run locally

Open `index.html` in a modern browser. For best results, use a simple local static server (for example, VS Code Live Server). The page does not require a build step or package installation.

## Images and credits

The supplied doctor portrait is stored locally in `assets/`. The additional editorial healthcare/clinic photographs currently use individual image URLs from Unsplash and are intentionally unique across the page. The current build environment could not reach the image host to download those stock photographs into the ZIP. They therefore load from their original URLs when the website is online. See `assets/README.md` for the image URL manifest and a download helper script to cache them locally when internet access is available.

## Verified information and safety

Professional profile details and areas of expertise were cross-checked against publicly indexed professional/hospital profiles, including Aga Khan University and South City Hospital. Appointment buttons point to the supplied booking URL. The website avoids unverified prices, guaranteed outcomes, patient testimonials and before/after claims. Please review all clinical wording, practice locations and appointment details with the doctor/client before publishing.

## Before deployment

- Confirm the exact clinic locations and contact details.
- Review all medical copy and credentials with the doctor.
- Confirm the rights/licensing for any stock images if you decide to self-host them.
- Upload the project folder to your static hosting provider.
